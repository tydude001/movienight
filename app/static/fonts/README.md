# Fonts

Vendored like htmx and Chart.js, so a page load fetches nothing from a third
party. Latin subset only, as served by Google Fonts (2026-10-17). All three
families are under the SIL Open Font License 1.1, which permits bundling them.

| File | Family | Weights |
| --- | --- | --- |
| `big-shoulders-display.woff2` | Big Shoulders Display | variable, 100–900 |
| `instrument-sans.woff2` | Instrument Sans | variable, 400–700 |
| `ibm-plex-mono-500.woff2` | IBM Plex Mono | 500 |
| `ibm-plex-mono-600.woff2` | IBM Plex Mono | 600 |

To upgrade, replace the files and keep the `@font-face` rules at the top of
`../style.css` in step.
